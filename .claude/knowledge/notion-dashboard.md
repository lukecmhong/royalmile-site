# notion-dashboard — 노션 화면 설계 원칙

노션 페이지·DB·보기를 만들거나 고치는 모든 작업 전에 읽는다. learn-source 규칙과 같이 맨 아래 추가만.

### 2026-10-26 · 출처: 외부 조사(matthiasfrank.de Notion Dashboards 101, thomasjfrank.com, Notion 공식 도움말) + 사용자 교정
- [원본 DB] → 원본(백엔드)은 메인 화면에 펼치지 않는다. 메인에는 WORK 메뉴 같은 링크로만 둔다. 메인은 프론트엔드다.
- [메인에 보기를 붙일 때] → 반드시 "지금 내 일"로 필터한다(오늘, 진행 중, 대기, 이번 주). 필터 없이 전체가 나오면 중복이다. 사용자가 "겹친다"고 교정한 사례: 메인에 STUDY 인사이트 전체 목록을 펼친 것.
- [보기 블록 모양] → 데이터 소스 제목을 숨기고(show_data_source_title=false), 기존 대시보드와 같은 콜아웃(아이콘 + 굵은 제목) 안에 넣는다. 맨 아래에 날것으로 이어 붙이지 않는다. 사용자 교정: "UI UX가 이게 뭐야".
- [레이아웃] → ICD 홈은 2단: 왼쪽 탐색(WORK·TOOLS 회색 콜아웃), 오른쪽 작업(인박스 → 오늘 업무일지 → 판단 대기·이번 주 브랜드 2열 카드), 맨 아래 할일·일정 캘린더(사용자가 직접 체크하는 입력 장치이므로 유지).
- [아이콘] → 회색 계열 노션 아이콘 한 가족으로 통일(pencil, hammer, attachment, flag, star …). 이모지 섞지 않는다.
- [같은 개념의 보기가 둘 이상] → 블록을 따로 만들지 않고 한 블록 안의 탭으로 합친다(예: 결정 대기 / 재검토 도래).
- [레코드 대시보드] → 프로젝트 같은 개별 페이지는 그 자체가 대시보드다. 관련 DB는 양방향 관계로 연결해 프로젝트 페이지 안에서 결정 기록·브랜드 후보·회의기록이 보이게 한다.
- [템플릿 행] → "프로젝트 템플릿"처럼 실제 항목이 아닌 행은 보기 필터로 숨긴다. 지우지 않는다.
- [작업 순서] → 노션 화면을 바꾸기 전에 대상 페이지를 fetch로 읽고, 기존 구조(콜아웃·컬럼·구분선)를 그대로 따라 끼워 넣는다.
