# 브랜드 탐색 파이프라인

메인 세션이 비서 역할. 수집은 넓게, 채점은 좁게. 전부에 심사위원을 붙이면 사용량만 낭비된다.

## 검토 영역 (사용자가 정한 14개)

Tea, Dining, Wellness, Longevity, Recovery, Golf, Hospitality, Bath/Sauna, Senior Luxury, Cultural Experience, Private Club, High-end Education, Craft, Lifestyle

## 핵심 질문 (수집과 채점 모두에 적용)

- 한국 부유층(40~60대 자산가 중심)은 앞으로 어디에 돈을 쓸 것인가
- 서울에서 1시간 이상 이동해서라도 소비할 경험은 무엇인가
- 한국에 아직 없지만 해외에서는 이미 검증된 생활문화는 무엇인가
- 직접 만드는 것과 해외 브랜드를 가져오는 것 중 무엇이 나은가
- 라이선스 / JV / 운영권 / 판권 중 어떤 구조가 가능한가

## 채점 기준 8개 (각 0~3점, 근거 필수)

실제 수요와 지불의사 / 운영 난이도(낮을수록 높은 점수) / 초기 자본(낮을수록 높은 점수) / 적합 입지 존재 / 회사 프로젝트와의 결합 가능성 / 복제 가능성 / 장기 지속성 / 권리 확보 가능성

## 0. 접수

- 영역 지정이 있으면 그 영역만, 없으면 요일별로 2~3개 영역을 순환한다 (월: Tea·Dining·Craft / 화: Wellness·Longevity·Recovery / 수: Golf·Hospitality / 목: Bath·Private Club·Senior Luxury / 금: Cultural·Education·Lifestyle). 순환 상태는 노션 후보 DB의 마지막 기록에서 읽는다.
- 노션 브랜드 후보 DB를 읽어 이미 기록된 브랜드 목록을 확보한다 (중복 제거용).

## 1. 수집 (researcher 1명, 브리프 C 변형)

`researcher` 에 "브랜드 수집" 브리프를 준다. 목표: 해당 영역에서 **최대한 많이**. 각 항목에 브랜드명 / 국가 / 시작 연도 / 매장·거점 수 / 공식 사이트 / 한국 진출 여부 / 출처 / 조회일. 평가는 금지. 접근 실패한 매체는 보고서 상단에 적는다.

## 2. 1차 걸러내기 (메인 세션, 워크플로우)

조건 세 개를 전부 통과한 것만 남긴다.
1. 한국 미진출 (또는 공식 진출 없음)
2. 본국 외 1개국 이상 또는 본국 내 2개 거점 이상 (검증 사례)
3. 공식 사이트나 공식 채널 존재

후보 DB와 대조해 이미 있는 것은 제외. 남은 것이 15개를 넘으면 핵심 질문 5개에 가장 가까운 순으로 15개까지 자른다.

## 3. 채점 (병렬 3명)

남은 후보 목록을 `reviewer-developer` (권리 구조·초기 자본·복제 가능성·지속성), `reviewer-operator` (수요·지불의사·운영 난이도), `reviewer-architect` (적합 입지·회사 프로젝트 결합 가능성·공간 요건) 에 **동시에** 넘긴다. 각자 담당 기준만 채점하고 근거를 쓴다. 담당 외 기준은 채점하지 않는다.

## 4. 합산과 최종 5

세 채점을 합산한다. 동점이면 "권리 확보 가능성"이 높은 쪽을 올린다. 상위 5개를 확정한다. 6~10위는 "다음 후보"로 보관한다.

심사위원 간 점수가 크게 갈리는 브랜드(어느 기준에서 0점과 3점이 동시에 나온 경우)는 최종 5에 들어가더라도 그 충돌을 표시한다.

## 5. 기록 (노션 브랜드 후보 DB)

최종 5개를 각각 한 건으로 추가. 속성: 브랜드명, 국가, 영역, 합산 점수, 8개 기준 점수, 도입 구조 후보(직영·JV·라이선스·판권), 적용 가능 프로젝트·입지, 예상 고객, 핵심 리스크, 출처, 조회일, 상태 = 후보. 본문에 심사위원 채점 근거 전문.

노션 미연결 시 스크래치 폴더에 저장하고 "미기록"으로 보고.

## 6. 검수

최종 5개 요약을 `auditor` 에 보낸다. 출처 없는 브랜드, 한국 진출 여부 미확인, 점수 근거 없음이 있으면 보류. 보류 항목은 최종 5에서 빼고 6위 이하에서 채운다.

## 보고

```
## 오늘의 5개 (영역, 한 줄 요약, 합산 점수, 도입 구조 후보)
## 심사위원 충돌 (있으면)
## 다음 후보 5개 (이름만)
## 수집 통계: 수집 N → 1차 통과 M → 채점 15 → 최종 5
## 접근 실패 매체
## [학습 후보]
```

## 특정 브랜드 1개 평가일 때

0과 1을 건너뛰고, 조사원에게 그 브랜드의 사실(연혁, 거점, 재무 공개 정보, 한국 진출 시도 이력, 권리 보유자)만 모으게 한 뒤 3~6을 그대로 돌린다.

## 승인 경계

브랜드 측 접촉, 메일 발송, 소장님 전달은 하지 않는다.
