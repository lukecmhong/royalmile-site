# 노션 세션 작업 목록

먼저 `.claude/knowledge/notion-dashboard.md` 와 `notion-contract.md` 를 읽는다. 노션 화면을 바꾸기 전에 대상 페이지를 fetch로 읽는다.

## 끝난 것 (2026-10-26)

- ICD 홈 2단 배치: 왼쪽 WORK·TOOLS 메뉴, 오른쪽 인박스 → 오늘 업무일지 → 판단 대기·이번 주 브랜드, 아래 캘린더.
- 결정 기록·브랜드 후보 DB 신설, 프로젝트 DB와 양방향 관계.
- **ICD 팀 사무실** 페이지(WORK 메뉴 맨 위): 직원 카드 8장, 업무 요청 진행판, 팀 보고 최근 7일. 직원 페이지를 열면 맡은 업무와 보고가 함께 보인다.
- 업무 요청 ↔ 프로젝트 양방향 관계(프로젝트 쪽 속성 이름 "팀 업무").

## 남은 것 (사용자가 "우선은 노션에 해보자"로 승인한 설계)

1. 홈 상단에 한 줄 메뉴(프로젝트 · 상시 업무 · 지식 · 기록 · 팀 · TOOLS · 보관함)로 WORK·TOOLS 콜아웃 대체.
2. 오늘 브리핑 칸: 팀 보고에서 오늘 날짜 + 종류 아침 브리핑 1건만 보이게.
3. 숫자 3칸: 이번 주 남은 할 일, 진행 중 프로젝트 수, 판단 대기 수(결정 대기 + 팀 보고 판단 필요).
4. 2단 작업 영역: 왼쪽 할 일(늦음 / 오늘 / 이번 주 탭), 오른쪽 진행 중 프로젝트 카드(진행률, 다음 할 일).
5. 캘린더를 주간 보기로.
6. 프로젝트 DB 속성 추가: 유형, 위치, 진행률(할 일 완료 비율), 다음 할 일. 할일·일정에 "늦음" 수식.
7. 프로젝트 페이지 레이아웃: 상태·기간·유형·위치·진행률 고정, 팀 업무·결정 기록·회의기록 보기, 5페이지 체크리스트.
8. 데이터 정리 후보(조사 후 사용자 승인): 프로젝트별 "프로젝트 과정" DB 통합 여부, 미팅과 회의기록 중복, STUDY 안 인사이트 이중 구조.
9. 버튼 블록("+ 업무 요청", "+ 할 일", "+ 회의 기록")은 API로 못 만든다. 사용자에게 1분짜리 안내.

삭제나 기존 기록 수정이 들어가는 항목은 사용자 승인 후에만 한다.
